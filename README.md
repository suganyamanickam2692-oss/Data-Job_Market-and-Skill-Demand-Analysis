
## Project Title

**Data Job Market and Skill Demand Analysis**

## Description

This project analyzes job posting data to understand current trends in the data and analytics job market. The analysis focuses on job roles, in-demand skills, salary ranges, seniority levels, locations, company size, and work modes such as remote, hybrid, and onsite.

Python will be used for data cleaning, transformation, and exploratory data analysis, while Power BI will be used to create interactive dashboards and visualizations. The project aims to identify the most demanded skills, understand salary patterns, and provide useful insights into the skills and job characteristics that are valued in the data industry., and visualization, while Power BI is used to create an interactive dashboard for discovering meaningful business and career insights.
